# Security policy

3B Infrastructure is a static website with no login, no database and no user data, so the risk is small. We still want to hear about anything that could harm people visiting the site.

## Supported versions

Only the latest release on `main` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/Three-Bugs-Studio/3binfrastructure/security/advisories/new) instead, with the steps to reproduce it and what an attacker could do.

We aim to reply within seven days.
